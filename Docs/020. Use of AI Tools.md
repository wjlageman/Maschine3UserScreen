# Use of AI Tools Within This Project

A large part of both the C++ code and the Javascript code of this project was written interactively with the help of ChatGPT 5.5. At the start of the project, Codex was not yet available. Development was therefore carried out largely through normal chat sessions with ChatGPT.

AI tools such as ChatGPT prove to be particularly valuable for:

- gathering technical background information
- analysing existing code
- designing software architecture
- writing new code
- writing boilerplate code
- generating example implementations
- analysing error messages
- writing documentation and manuals
- designing screen layouts and widgets
- generating HTML layouts and user interfaces

Particularly for C++, Javascript, and Python, ChatGPT's knowledge base is broad. Knowledge of USB, HID, OSC, Sciter, libusb, and embedded display protocols also proved useful in practice.

ChatGPT also has some knowledge of Max and MaxForLive. This knowledge is more limited than its support for C++, Javascript, and Python, but is still useful for patches, OSC communication, simple integrations, and support when debugging Max patches.

In addition, ChatGPT can be used as a sounding board at a more abstract level, for example for architectural choices, workflows, user interfaces, debugging strategies, and the overall direction of a project. The advice provided by ChatGPT is by no means always followed, but it helps the developer to consider different possibilities and make well-informed decisions.

## The Role of the Developer

Within this project, ChatGPT is not used as an autonomous programmer, but as a technical assistant. The developer remains fully responsible for the architecture, the quality of the code, and the overall direction of the project.

This is important because AI systems quickly tend to work outside the existing architecture when they are not actively supervised.

When ChatGPT is given too much freedom, problems can arise within a short period of time, such as:

- duplicate implementations of the same functionality
- unwanted refactors
- inconsistent naming
- an architecture that gradually grows apart
- helper functions that make existing code unnecessarily complicated
- new abstraction layers that do not fit within the project
- code that does not conform to existing conventions

Without active supervision by the developer, a project can therefore become difficult to manage in a very short time.

For that reason, this project uses:

- small, controlled steps
- regular inspection of generated code
- fixed programming conventions
- strict naming conventions
- clear separation between modules
- continuous monitoring for unwanted refactors

New code is always tested locally before it becomes part of the project.

## Working Method Within This Project

For larger changes, complete source snapshots are uploaded as ZIP files. This allows ChatGPT to follow the existing architecture, naming conventions, and code more accurately.

Documentation files and manuals can also be uploaded. This helps maintain consistent terminology and project structure.

The usual workflow is:

- formulate a clear technical goal
- upload the relevant source files
- describe a specific modification or extension
- inspect the generated code
- test the code locally
- correct problems in small follow-up steps

## Limitations of AI Tools

AI tools remain tools. Especially when dealing with complex debugging, timing issues, USB communication, HID protocols, and race conditions, manual analysis by the developer remains necessary.

In addition, AI systems sometimes make assumptions without fully checking the current source code. For that reason, all modifications should be reviewed critically.

AI tools can significantly accelerate software development, but they require clear technical guidance and continuous supervision by the developer.

## Advice for Modifications and Further Development

For maintenance and further development of the project, the use of ChatGPT is also recommended. Based on the available manuals, the existing source code, and current project files, ChatGPT can often quickly generate correct extensions, bug fixes, and modifications.

Developer supervision remains necessary in this case as well, but the combination of existing documentation and current source snapshots makes it possible to continue development relatively efficiently.

## Summary

Within this project, ChatGPT is used as a technical assistant for research, documentation, architecture, and code generation. The developer continuously remains in control of the architecture, code quality, and the final technical decisions.
