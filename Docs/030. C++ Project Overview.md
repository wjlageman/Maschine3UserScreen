# Overview of the C++ Project

The Visual Studio solution consists of three separate projects:

- Maschine3UserScreen
- MaschineUsbControls
- MaschineUsbControlsTester

## 1. Maschine3UserScreen

This is the main application of the project. This console application is responsible for:

- taking control of the Maschine MK3 displays
- communication with the Sciter HTML/JS environment
- OSC communication via UDP
- integration with controller events
- rendering widgets and screen layouts
- low-level display updates via WinUSB/libusb

Important components within this project are:

- **Maschine3UserScreen.cpp/h**: low-level display interface
- **SciterSession.cpp/h**: startup and management of the Sciter session
- **SciterWindow.cpp/h**: connection between Sciter and native C++
- **SciterTemplate.cpp/h**: loading of `.htm` templates
- **Maschine3ControlsRouter.cpp/h**: routing of controller events to OSC and Javascript
- **Udp_osc_transport.cpp/h**: OSC communication via UDP
- **GraphicHelpers.cpp/h**: simple low-level drawing functions
- **BannerDemo.cpp/h**: minimal demonstration for direct screen takeover

## 2. MaschineUsbControls

This project contains the native DLL for the Maschine MK3 controls and LEDs.

The DLL is responsible for:

- reading HID control reports
- decoding buttons, encoders, touch strip, and pads
- LED control via HID output reports
- mapping controls and LEDs to names and indexes

Important files:

- **MaschineUsbControls.cpp/h**: HID communication and event decoding
- **WidgetLookup.cpp/h**: mapping of control bits to control names
- **LedIndex.cpp/h**: mapping of LEDs and colour indexes

## 3. MaschineUsbControlsTester

This is a simple test application for the MaschineUsbControls DLL.

The tester is used for:

- rapid validation of control events
- testing HID communication
- testing LED updates
- debugging the native DLL without the complete screen application

## Architecture

The solution has deliberately been divided into separate components:

- display interface
- controller interface
- LED interface
- Sciter HTML/JS environment
- OSC communication

As a result, the various hardware and software layers remain relatively well separated. The low-level HID and USB code is located primarily in native C++, while the user interface and widgets are managed from the Javascript/Sciter environment.
